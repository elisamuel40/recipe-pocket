# Recipe Pocket
An open-source Chrome extension project for reading and managing recipes locally.

**Status: version 0.1.0 developer build. Install it in Chrome's developer mode; it is not on the Chrome Web Store yet.**

No account. No analytics. Recipes saved only on your device. This site hosts documentation; the product runs inside Chrome.
