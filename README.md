# Recipe Pocket — open-source Chrome extension build package
Working name; trademark availability not checked. Prepared October 31, 2026.

This is an implementation handoff, not a finished extension. The extraction probe is executable research, not end-to-end app validation. No account, analytics, backend, subscription, or developer-held recipe data. Product UI lives inside Chrome. GitHub Pages hosts only public documentation, privacy policy and installation guidance.

## Read in order
1. PRD.md — scope, behavior and acceptance requirements
2. ARCHITECTURE.md — implementation contracts and privacy boundaries
3. AGENTS.md — agent execution instructions and work breakdown
4. TESTING.md and site-probe-results.json — evidence and release gates
5. docs/privacy.md, docs/terms.md — publication drafts
6. RELEASE.md — open-source and GitHub Pages deployment

All public documents are drafts until the built extension has been audited against them. Owner identity and support URL are release-blocking placeholders. All premium-equivalent product capabilities are in scope; video import remains a research gate, not a promise of compatibility with every social platform. No app implementation is represented as complete.
